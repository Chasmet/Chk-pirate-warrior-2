# Bateaux GLB — CHK Pirate Warrior 2

Ce dossier contient des embarcations et navires 3D légers destinés à la navigation, aux PNJ maritimes et aux décors du jeu.

## Organisation

- `glb/` : modèles 3D optimisés au format GLB ;
- `png/` : aperçu PNG 512×512 de chaque bateau ;
- `LICENSE_SOURCES.md` : licence et provenance des modèles.

## Premier lot CC0

- `barque_grande.glb`
- `barque_petite.glb`
- `navire_pirate_sombre.glb`
- `navire_pirate_clair.glb`
- `epave_navire.glb`

Les mêmes noms sont utilisés dans `png/` pour les aperçus.

Ces modèles servent de base légère pour :

- bateau de pêche ;
- bateau civil ;
- navire pirate ;
- navire marchand ;
- épaves et événements en mer.

Les variantes de couleurs, voiles, pavillons et équipement pourront être créées dans Godot afin d'éviter de dupliquer inutilement les meshes.
