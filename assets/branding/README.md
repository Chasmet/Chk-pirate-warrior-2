# Logo et identité de l'application

Déposer ici :

- logo principal du jeu ;
- icône de l'application Android/APK ;
- écran de lancement ;
- bannière GitHub ;
- images Play Store ;
- miniatures ;
- logo monochrome ;
- variantes carrées, horizontales et verticales.

Formats conseillés :
- logo transparent : `.png` ;
- icône APK : image carrée haute définition ;
- écran de lancement : portrait Android ;
- bannière : format horizontal.

Noms conseillés : `logo_principal.png`, `icone_apk.png`, `splash_screen.png`, `banniere_store.png`, `logo_noir_blanc.png`.
