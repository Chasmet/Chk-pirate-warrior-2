# Organisation des équipages

Ce dossier contient un emplacement séparé pour chacun des 10 équipages du jeu.

## Structure

- `ile_01/` à `ile_10/` : personnages, bateau et références propres à chaque île.
- Les vidéos actuelles des trois personnages principaux restent à la racine du dépôt pour éviter toute perte ou modification involontaire.

## Formats conseillés

- Images transparentes : `.png` ou `.webp`
- Modèles 3D : `.glb` ou `.gltf`
- Vidéos de référence : `.mp4`
- Textures : `.png`, `.jpg` ou `.webp`

## Règle de nommage

Utiliser des noms sans espaces ni accents, par exemple :

- `ile_01_personnage_01.png`
- `ile_01_personnage_02.png`
- `ile_01_bateau.png`
- `ile_01_bateau.glb`
- `ile_01_reference_equipage.mp4`

Ne pas supprimer les fichiers `README.md` : ils servent de guide pour chaque dossier.
