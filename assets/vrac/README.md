# Assets en vrac

Déposer ici tout élément qui n'est pas encore affecté à un royaume ou à une mission.

Catégories possibles :
- bateaux ;
- animaux terrestres ou marins ;
- personnages ;
- ennemis ;
- armes ;
- objets ;
- bâtiments ;
- végétation ;
- textures ;
- effets ;
- vidéos de référence.

Renommer ensuite les fichiers proprement avant leur intégration dans le jeu.
