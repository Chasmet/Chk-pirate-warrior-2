# Équipements des héros

Ce dossier contient les équipements visibles sur les personnages principaux.

## Sacs à dos obligatoires

- Cheikh : `sacs_a_dos/glb/sac_cheikh_orange.glb`
- Yvane : `sacs_a_dos/glb/sac_yvane_bleu.glb`
- Nelvyn : `sacs_a_dos/glb/sac_nelvyn_noir.glb`

Le sac doit rester visible sur le dos du héros pendant l'exploration, les combats et les déplacements en bateau. Il représente physiquement l'inventaire du joueur.

Objets prévus : pièces, boussoles, coffres, cartes, clés, potions, matériaux de bateau, objets rares et objets spécifiques aux îles.

## Armes principales

- Cheikh : batte de baseball `armes/glb/batte_cheikh.glb`
- Yvane : combat aux poings, aucune arme tenue par défaut
- Nelvyn : épée `armes/glb/epee_nelvyn.glb`

Les modèles générés sont volontairement légers pour Android. Les images PNG du sous-dossier `png/` servent d'aperçu.
