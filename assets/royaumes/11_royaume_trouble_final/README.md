# 11 — Royaume Trouble — Île finale

Cette île correspond clairement à la fin du jeu.

## Signes visibles de fin de jeu

- ciel instable et couleurs déformées ;
- mélange d'éléments provenant des dix royaumes précédents ;
- musique finale unique ;
- messages annonçant l'approche du dernier combat ;
- grande porte ou portail marqué comme point de non-retour ;
- boss final et cinématique de conclusion ;
- générique après la victoire.

## Récompense finale proposée

Après avoir terminé le Royaume Trouble, le joueur gagne :

- le bateau légendaire `Navire du Chaos` ;
- le titre `Maître des 11 Royaumes` ;
- un équipage spécial déblocable ;
- le mode `Nouvelle Aventure +` ;
- une tenue finale exclusive pour Cheikh, Yvane et Nelvyn.
