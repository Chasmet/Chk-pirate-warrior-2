# Player 03 — Nelvyn

Déposer ici toutes les versions de Nelvyn : images, vidéos, modèles 3D, textures, animations, tenues, armes, voix, effets et bateaux personnels.

Organisation conseillée :
- images de face, profil et dos ;
- poses et expressions ;
- vidéos de référence ;
- modèle 3D `.glb` ;
- textures ;
- animations ;
- deux bateaux personnels ou davantage ;
- tenues normales et finales.

Noms conseillés : `nelvyn_face.png`, `nelvyn_profil.png`, `nelvyn_modele.glb`, `nelvyn_bateau_01.glb`, `nelvyn_bateau_02.glb`, `nelvyn_reference.mp4`.
