# Player 02 — Yvane

Déposer ici toutes les versions de Yvane : images, vidéos, modèles 3D, textures, animations, tenues, armes, voix, effets et bateaux personnels.

Organisation conseillée :
- images de face, profil et dos ;
- poses et expressions ;
- vidéos de référence ;
- modèle 3D `.glb` ;
- textures ;
- animations ;
- deux bateaux personnels ou davantage ;
- tenues normales et finales.

Noms conseillés : `yvane_face.png`, `yvane_profil.png`, `yvane_modele.glb`, `yvane_bateau_01.glb`, `yvane_bateau_02.glb`, `yvane_reference.mp4`.
