# Player 01 — Cheikh

Déposer ici toutes les versions de Cheikh : images, vidéos, modèles 3D, textures, animations, tenues, armes, voix, effets et bateaux personnels.

Organisation conseillée :
- images de face, profil et dos ;
- poses et expressions ;
- vidéos de référence ;
- modèle 3D `.glb` ;
- textures ;
- animations ;
- deux bateaux personnels ou davantage ;
- tenues normales et finales.

Noms conseillés : `cheikh_face.png`, `cheikh_profil.png`, `cheikh_modele.glb`, `cheikh_bateau_01.glb`, `cheikh_bateau_02.glb`, `cheikh_reference.mp4`.
