# Audio

Déposer ici les musiques, ambiances, voix, dialogues enregistrés et bruitages du jeu.

Organisation conseillée :
- thèmes des royaumes ;
- musique de combat ;
- musique de boss ;
- ambiance mer, vent, pluie, feu et neige ;
- pas, impacts, armes et pouvoirs ;
- voix de Cheikh, Yvane, Nelvyn et des PNJ.

Formats conseillés : `.ogg` ou `.wav`.
