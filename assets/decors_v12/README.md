# Décors originaux CHK V12

Huit GLB originaux générés par `tools/generate_v12_scenery.py`, intégrés dans les
onze royaumes par `scripts/world/scenery_v12.gd`. Géométrie fusionnée par matériau,
unités en mètres, axe Y vertical, aucune texture externe et aucun Draco.

Phare, marché, arche, sanctuaire, réserves, bannière, passerelle et corail.
Le phare, le cristal du sanctuaire et la bannière contiennent une animation GLB.
Les collisions sont ajoutées en jeu, en gardant le passage de l'arche libre.
Le sanctuaire soigne à proximité hors combat et sauvegarde la progression.

Créations pour ce dépôt ; aucune ressource tierce téléchargée pour ce kit.
Le manifeste indique les tailles et les triangles réellement générés.
